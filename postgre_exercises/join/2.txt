Question
How can you produce a list of the start times for bookings for tennis courts, for the date '2012-09-21'? Return a list of start time and facility name pairings, ordered by the time.

select
  cd.bookings.starttime as start,
  cd.facilities.name as name
from
  cd.bookings
join
  cd.facilities ON cd.bookings.facid = cd.facilities.facid
where
  cd.bookings.starttime >= '2012-09-21 8:00:00'
and cd.bookings.starttime < '2012-09-21 18:00:01'
and cd.facilities.name like 'Tennis Court%'
order by
  cd.bookings.starttime;
